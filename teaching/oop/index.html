How to use this material

Select a lesson in the left navigation. Work through Learn, Trace, Predict, Run, Experiment, Practice, and Checkpoint. Previous and Next follow the recommended order. View all is available for searching across the material and printing.

For programs using cin, enter all input before Run. Code and input are sent to Compiler Explorer; execution requires internet access and service availability. The examples use C++17.

Memory diagrams follow their supplied traces, not arbitrary edited programs. Sample-output checks use one disclosed input/output case; the Classes mini-project has six focused code checks. Neither is a secure grading system.
