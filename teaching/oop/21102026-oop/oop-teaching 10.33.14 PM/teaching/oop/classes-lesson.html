1 · Learn

Why put variables and functions together?

A point in a plane needs two coordinates. With separate variables, you might write x1, y1, x2, and y2. As the program grows, it becomes easier to mix up which values belong together. A class defines a new type that groups related data and the operations on that data.

For Point, the coordinates are its state. Moving the point and printing it are its behavior. Point is the type; p1 and p2 are objects of that type.

TermMeaning in this example
ClassPoint defines the members and operations.
Objectp1 is one instance of Point.
Data memberx and y store each object’s coordinates.
Member functionsetX, moveBy, and print operate on a selected object.
Public interfaceThe operations calling code is allowed to use.

Read a small class declaration

class Point {
private:
    int x, y;
public:
    Point(int initialX=0, int initialY=0)
        : x(initialX), y(initialY) {}
    int getX() const { return x; }
    void setX(int value) { x=value; }
}; // The semicolon ends the class declaration.

The labels private: and public: control access to the members that follow them. A class has private access by default. A member function can read or change private data; unrelated code in main cannot access it directly.

Point p1(2,3);
p1.setX(8);              // Allowed: public function.
cout << p1.getX();      // Allowed: public query.
// p1.x = 8;             // Compile error: x is private.

This separation is encapsulation: callers work through an interface while the class controls its representation and rules. A getter for every field is not mandatory. Offer operations that make sense for the type. Private access is a language rule, not encryption or a protection against reading process memory.

Constructors establish the initial state

A constructor has the same name as its class and has no return type. It runs as an object is created. The initializer list : x(initialX), y(initialY) initializes members before the constructor body starts.

Point p1(2,3);  // x=2, y=3
Point p2;       // x=0, y=0, using default arguments
Point p3(8);    // x=8, y=0
// Point p4();  // Caution: this declares a function, not an object.

Our constructor is also a default constructor because it can be called with no arguments. That is different from explicitly writing = default. Do not assume built-in members are automatically zeroed: this example initializes them deliberately.

Queries observe; commands update

getX() const is a query. The trailing const promises not to modify ordinary instance data through that call. setX and moveBy are commands that update the selected object. A const object can call const queries but cannot call these updating functions.

const Point fixed(2,3);
cout << fixed.getX();   // Allowed.
// fixed.setX(8);        // Compile error: changes a const object.

3 · Predict before you run
Which object changed?
Point p1(2,3), p2;
p1.print();
p2.print();
p2.setX(8);
p1.moveBy(1,-1);
p1.print();
p2.print();
Explain the output
(2,3)
(0,0)
(3,2)
(8,0)
p2 uses the constructor defaults. setX changes only p2’s x coordinate. moveBy changes p1 from (2,3) to (3,2). p2.y remains 0.

5 · Experiment
Change one thing and explain what happens
Change the defaults
In the basic Point program, change the constructor defaults to 5 and 6. Predict the effect on p1(2,3) and on p2.
Expected observation
Explicitly supplied arguments keep p1 at (2,3). Only omitted arguments use the new defaults, so p2 begins at (5,6).
Try direct access
Add p1.x = 99; in main and compile. Read the diagnostic, then restore a valid call using setX.
Expected observation
The compiler rejects access to private x. p1.setX(99); uses the public interface and compiles.
Protect a const object
Declare const Point p(2,3);. Try getX, print, and setX on it.
Expected observation
getX and print are const queries and compile. setX changes state and is rejected. The const qualifier belongs after the parameter list of a const member function.
Reject an invalid grade
Try grades -1, 0, 100, and 101 with setGrade. Print the return value and the grade after each call.
Expected observation
0 and 100 are accepted. -1 and 101 return false and preserve the previous valid grade. The rule is a teaching range, not a university policy.
Intentionally invalid experiments can fail to compile. Reset restores a runnable original. Use Edit code in the relevant program above to perform these experiments.

Common mistakes to recognize
  • Missing the semicolon after the class: end the declaration with };.
  • Giving a constructor a return type: constructors do not declare one, including void.
  • Reading uninitialized members: initialize every built-in member the program relies on.
  • Assuming objects share instance data: changing p2 does not change p1 in these examples.
  • Making all data public to avoid compiler errors: use an appropriate interface and protect the class’s rules.
  • Thinking const returns a constant object: a trailing const describes the member function’s access through its calling object.
