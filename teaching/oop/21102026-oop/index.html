Start with a prediction. Read each example, work out what it should do, then run it. Use Edit code to experiment and Reset to restore the original.

For programs using cin, enter all input before pressing Run. Code and input are sent to Compiler Explorer; execution requires internet access and service availability. The examples use C++17.

Intentional errors stay commented out so the supplied programs compile. Sample output is from verified local runs. Revision groups eight foundation lessons. Classes and Objects adds a visual trace, prediction feedback, and a mini-project with six coding checks. Other exercises have hints and worked solutions.
